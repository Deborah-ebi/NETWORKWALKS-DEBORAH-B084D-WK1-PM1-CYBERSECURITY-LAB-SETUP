# Network Cybersecurity Lab

## Project Overview

This project documents the setup and configuration of my virtual lab for ethical hacking and penetration testing as part of my Networks internship.

The lab provides an isolated environment for learning cybersecurity concepts, practising basic network analysis, and conducting authorised security testing.

## Objectives

- Set up a virtual lab environment.
- Configure a virtual machine for cybersecurity practice.
- Verify network connectivity.
- Document the lab setup and testing process.
- Build practical skills in ethical hacking and penetration testing.

## Tools and Technologies

- Oracle VM VirtualBox
- Kali Linux
- Windows host operating system

## Lab Setup

The virtual lab was prepared using VirtualBox and Kali Linux.

The configuration and testing details will be documented here based on the actual environment used.

## Testing and Verification

Network connectivity and other relevant lab functions will be documented with evidence from the completed tests.

## Learning Outcomes

This project supports my practical learning in virtualisation, Linux environments, network configuration, and cybersecurity lab preparation.
